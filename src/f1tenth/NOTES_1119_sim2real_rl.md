## 3. 결정 사항과 근거

1. **지연은 IL과 RL 모두에 넣는다.** 지연 없는 시뮬레이터에서 RL을 하면 즉시 반응을 전제로 공격적으로 꺾는 정책이 나와 실차에서 더 흔들린다. 단, **값은 측정 후 다시 정한다**.
   - 측정 후: 기준값 = 측정값, 범위 = 측정값 × 0.7~1.5.
   - 측정 전에 학습해야 하면: 범위를 **0.05~0.30 s**로 넓혀 짧은 지연도 포함한다(지금 하한 0.10 s는 실제보다 길 수 있다).
   - IL과 PPO의 지연 설정은 반드시 같게 한다.
   - 행동 이력 길이(현재 10 = 0.25 s)는 최대 지연 이상이어야 한다. 지연 상한이 0.30 s면 12 이상(관측 차원이 바뀌므로 IL부터 재학습).
2. **IL 초기화 + PPO가 처음부터 RL보다 낫다.** IL은 이미 완주율이 높고(run 7: 실차 조건 시뮬레이터에서 96.2%), RL은 그걸 개선만 하면 된다. 단, 레이스라인 추종 보상은 성능 상한이 레이스라인(=expert)이 되므로 쓰지 않거나 잠재함수 방식으로 초반 보조로만 쓴다.
3. **RL로 줄일 수 있는 것은 정책의 "늦게 반응하는 습관"**이다. 서보와 타이어의 물리적 지연 자체는 줄지 않는다. RL은 지연을 감안해 미리 꺾는 법을 배울 수 있다.

## 4. PPO 보상 설계 (추천)

핵심: **진행거리 + 스텝당 시간 벌점**. 2바퀴 진행거리 합은 항상 같으므로 총 보상 = 10·거리 − c·시간 → 랩 타임 최소화와 정확히 같다. 지금(진행거리만)은 속도 유인이 할인율에서만 나와 약하다.

```
r = 10·Δs                                   # 진행거리 (주 신호)
  − 0.1                                     # 스텝당 시간 벌점 (조건: c < 10·v_min·0.025, 1 m/s 기준 0.25)
  − 3·(Δ조향)²                              # 떨림 억제 (현재 5)
  − 5·max(0, 0.30 − 벽과 최소거리)          # 실차 안전 여유
  − 2·max(0, |횡가속도| − 0.8·μg)           # 접지 한계 근처 억제
  − 200 (충돌 시 종료)                       # 남은 에피소드 가치(3 m/s, 5초 ≈ 130)보다 크게
  + 랩 완주 시 2·max(0, 기준랩타임 − 랩타임)  # 선택, 작게
```
- 비추천: 속도 자체 보상(꼼수 가능), 생존 보너스(느리게 달림), 에피소드 끝에 총 거리만 주는 보상.
- 구현 위치: `utils/env.py` `calc_reward()`, 계수는 `train_ppo_s2r.py` 상단(`PROGRESS_COEFF`, `COLLISION_COST`, `STEER_RATE_COST`), 랩 보너스는 `env.py` `step()`에서 `self.lap_times`가 늘 때.

## 5. PPO 하이퍼파라미터 (추천, `train_ppo_s2r.py` 기준)

| 파라미터 | 현재 | 추천 | 이유 |
|---|---|---|---|
| return 정규화 | 없음 | **추가** | return이 수백 단위라 critic 학습이 느림. 효과가 가장 큰 개선 |
| critic warm-up | 3회 | 최소 3회 + explained variance ≥ 0.6까지 | critic이 부정확하면 IL 정책이 망가짐 |
| γ / GAE λ | 0.995 / 0.95 | 유지 | 약 5초 앞까지 봄 |
| actor lr | 5e-5 고정 | 5e-5 → 1e-5 선형 감소 | |
| clip / max_kl | 0.15 / 0.02 | 0.1~0.15 / 0.01~0.015 | IL 근처에서 조금씩 |
| log_std | −2.0 (둘 다 고정) | 조향 −2.5, 속도 −1.5, 후반 감소 | 조향 노이즈는 지연 때문에 흔들림·충돌로 직결 |
| BC 가중치 | 1.0 → 0.05 | 1.0 → 0.02, 평가 완주율이 IL보다 떨어지면 다시 올림 | |
| 속도 상한 없는 에피소드 | 25% | 50~60% (`f1tenth.yaml` `speed_limit.uncapped_prob`) | 상한에 걸리면 속도 학습 신호가 없음 |
| seed | 1 | 2~3 | |
| 모델 선택 | 완주율 → 평균 랩 타임 | 두 모델 모두 완주한 트랙끼리 짝지어 비교 + 최악 조건(긴 지연, 낮은 마찰) 완주율 | 평균 랩 타임은 완주한 트랙이 다르면 불공정 |

학습 중 기록할 것: explained variance, clip 비율, 행동 std, 충돌률, 평균 속도.
